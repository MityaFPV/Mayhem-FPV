[h1]Realistic 5" FPV drone simulator[/h1]

[hr][/hr]

[h2] WARNING! For using RC-controller you need to have FPVjoy module. Little intstruction down here: [/h2]
[olist]
[*]Download [b]gmcl_fpvjoy_win64.dll[/b] from [url=https://github.com/MityaFPV/Mayhem-FPV] GitHub releases page[/url].
[*]Put it in [b]garrysmod\lua\bin\[/b].
[*]Restart Garry's Mod.
[/olist]

[h2]Features[/h2]
[list]
[*][b]MayhemPhys 2.0[/b] -- Own physics, inspired by simulators such as: Liftoff, Uncrashed and TRYP FPV.
[*][b]Betaflight settings[/b] -- Rates, PIDs and etc.
[*][b]Analog OSD[/b] -- Changable Betaflight analog OSD.
[*][b]Analog video[/b] -- Glitches, noises, RX looses.
[*][b]LiPo battery[/b] -- Fully functional battery system.
[*][b]Crashes[/b] -- SMASH YOUR DRONE INTO TREE!
[/list]
